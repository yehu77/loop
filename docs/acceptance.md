# v1 合成数据工程验收

日期：2026-10-09。设备：WSL2 / RTX 2060 6GB；Python 3.10.20，PyTorch 2.10.0+cu128；环境 `code_rl_clean`。GPU 检查在获准的沙箱外执行。

## 已通过检查

- 27 项 unittest 全部通过（包含实际 CUDA AMP 溢出时跳过优化器与 EMA 的检查）。
- 同权重下循环一轮与 BASE 等价；共享参数梯度等于独立展开各次使用梯度之和；循环第一轮输出具有反向梯度。
- 三个模型经过多次更新后，全部可训练参数均得到有限非零梯度。
- CPU 上保存加载后的固定输入输出及下一次训练更新可精确重放，覆盖 EMA、优化器、随机数与数据迭代位置。
- GPU 上循环模型的 AMP 检查点从第 6 次更新恢复，并成功继续到第 8 次。
- CPU 命令行短训练与采样路径通过。

## RTX 2060 实测

每行各执行 6 次更新尝试，微批次 4、累积 8 次。采样使用 EMA、FP32 DDIM 50 步、两个条件，每个条件 100 条轨迹，场景微批次 16。全部运行无跳过更新，轨迹形状为 `[2, 100, 24, 1]`，数值有限且位于 `[0,1]`。

## 当前结果的限制

这些检查证明实现与运行路径可用，不代表学会了风电条件分布。仅 6 次更新且 EMA 衰减为 0.999 时，当前采样约 99.3% 的值落在零／满功率裁剪边界。该现象已保留在报告中，不能把合法取值范围或不同随机样本解释为概率预测质量。

尚未完成真实数据接入、预测发布时间审计、时间切分、概率指标、正式模型选择与公平计算预算对照。没有启动正式实验。
